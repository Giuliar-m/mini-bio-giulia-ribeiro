# Mini Site de Bio • Giulia Ribeiro

> **"Nos bastidores, cuidando de quem cuida."**  
> Assistente virtual para médicos e soluções digitais para uma presença profissional mais organizada e acolhedora.

---

Mini site de bio profissional e editorial desenvolvido para o perfil do Instagram de **Giulia Ribeiro**, substituindo os tradicionais agregadores de links genéricos por uma pequena landing page autoral, elegante e acolhedora.

## 🏛️ Conceito Visual: A Porta Aberta

O design é inspirado no conceito arquitetônico de uma porta de consultório aberta — simbolizando acolhimento, cuidado e entrada para um espaço de trabalho organizado e confiável.

### Paleta de Cores
- **Ameixa (`#3F2A32`)**: Textos principais, fundos escuros e alto contraste.
- **Rosé profundo (`#9C525E`)**: Cor de destaque principal e botões de ação.
- **Blush (`#F3DDD8`)**: Molduras suaves e detalhes arquitetônicos.
- **Sálvia (`#7E9A86`)**: Detalhes delicados, equilíbrio e calmaria.
- **Creme (`#FFF8F4`)**: Fundo base luminoso e sofisticado.

### Tipografia
- **Fraunces** (Google Fonts): Para títulos e frases de destaque com acabamento editorial de alta costura.
- **DM Sans** (Google Fonts): Para leitura fluida, informações e botões de toque no celular.

## 💻 Tecnologias Utilizadas

- **HTML5 Semântico**: Estrutura acessível com metadados para redes sociais, Open Graph e SEO.
- **CSS3 Puro**: Design responsivo mobile-first, variáveis CSS, moldura em arco e suporte a `prefers-reduced-motion`.
- **Vanilla JavaScript**: Interatividade leve e sem dependências externas.
- **Zero frameworks**: Sem React, Vue, Tailwind ou dependências desnecessárias.

## 🚀 Como Executar Localmente

Como o projeto é 100% estático, basta abrir o arquivo `index.html` em qualquer navegador:

1. Dê um duplo clique no arquivo `index.html`, **ou**
2. Inicie um servidor local via terminal:
   ```bash
   # Com Python
   python -m http.server 8080
   ```
3. Acesse `http://localhost:8080` no navegador.

## 🌐 Publicação no GitHub Pages

Para ativar a hospedagem gratuita pelo GitHub Pages:

1. Acesse o repositório no GitHub: `https://github.com/Giuliar-m/mini-bio-giulia-ribeiro`
2. Vá na aba **Settings** (Configurações).
3. No menu lateral esquerdo, clique em **Pages**.
4. Em **Build and deployment** > **Source**, selecione `Deploy from a branch`.
5. Em **Branch**, selecione `main` e a pasta `/ (root)`.
6. Clique em **Save**.
7. Em 1 a 2 minutos o site estará publicado no endereço:  
   `https://giuliar-m.github.io/mini-bio-giulia-ribeiro/`
